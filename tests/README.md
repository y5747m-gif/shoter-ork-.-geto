# اختبارات أورك زون

| الملف | ماذا يختبر | التشغيل |
|---|---|---|
| `smoke.test.js` | منطق اللعبة: بناء الخرائط الخمس بلا أخطاء، حتمية التوليد، الأسلحة، البوتات (٤ درجات)، مباريات كاملة (فردي/رباعي/ساحة)، الرصاص والمسار، العاصفة، المركبات، الإنزال الجوي، الأداء، REST | `npm test` |
| `loading.test.js` | شاشة التحميل لا تعلق: لا أي مورد خارجي (CDN) في الصفحة، كل الموارد المحلية والخطوط مخدومة 200، المراقب المبكر يُنهي التحميل لو لم يعمل `main.js` ولا يتدخل لو اكتمل، وطبقة «دوّر الجهاز» لا تحجب الكمبيوتر وتُتجاوز على الهاتف | `npm run test:loading` |
| `client.test.js` | عميل المتصفح داخل DOM حقيقي (jsdom): التحميل، الدخول، كل الشاشات، المتجر بكل أقسامه، الخزنة، الباس، الحلبة، مباراة أوفلاين كاملة + ١٤٠٠ إطار رسم على كل خريطة | `npm run test:client` |
| `online.test.js` | أونلاين عبر WebSocket: عميلان حقيقيان، غرفة برمز، لقطات، توقع، إقصاء، عاصفة، إنزال، دردشة، صمود السيرفر بعد الانقطاع | `npm run test:online` |
| `browser.test.js` | اختبار متصفح حقيقي (Puppeteer) + لقطات شاشة — يحتاج `npm i puppeteer --no-save` ومتصفحاً متاحاً | `node tests/browser.test.js` |
| `tools/preview.mjs` | توليد صور PNG للعبة (معارك + شخصيات + خرائط) | `npm run previews` |

> `loading.test.js` و `client.test.js` يحتاجان `jsdom` و `preview.mjs` يحتاج `@napi-rs/canvas` (موجودان في devDependencies).
> لثبيت خفيف بلا أدوات اختبار: `npm install --omit=dev`
